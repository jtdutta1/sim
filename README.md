# sim
A basic simulator for physics based systems written in C++

## Currently working
- A base particle class with positional value holding capabilities

## How to use it?
- Include the `particle.h` header file in your code. It can be found in `src/core/particle/particle.h`. 
- Compile your code with `src/core/particle/particle.cc`.
